# Automatic-File-Organizer-Project

📁 Automatic File Organizer

An automatic file organizer built in Python that sorts files into folders based on their file type or extension. This helps keep your directories clean and well-organized.

🚀 Features
Automatically organizes files by extension
Supports common file types (images, documents, videos, etc.)
Easy to use and beginner-friendly
Helps keep your system clean

🛠️ Technologies Used
Python

📂 How It Works
The script scans a selected directory and moves files into folders like:
Images → .jpg, .png
Documents → .pdf, .docx
Videos → .mp4, .mkv
Others → separate folders

▶️ How to Run
Make sure Python is installed

Clone this repository:
git clone https://github.com/your-username/Automatic-File-Organizer-Project.git

Go to project folder:
cd Automatic-File-Organizer-Project

Run the script:
python main.py
